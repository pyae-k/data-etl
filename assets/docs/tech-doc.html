ETL Studio — Technical Documentation

Architecture and technical details for the browser-based ETL tool.

Architecture

Built with React and DuckDB WASM. All data processing happens in-browser — no server uploads. The app uses Vite for bundling and Workbox for service worker management.

Data Flow

Files are loaded via the File System Access API or drag-and-drop, registered as virtual files in DuckDB WASM, then queried using SQL. Results are displayed in a virtual table and can be exported.
