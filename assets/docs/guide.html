ETL Studio User Guide

How to use the browser-based ETL tool.

Quick Start

  1. Click Connect to link a folder or database
  2. Load a CSV, Parquet, or JSON file
  3. Use the visual pipeline editor to add transform steps
  4. Run SQL queries or apply filters/aggregations
  5. Export results as CSV or Parquet

Privacy

All data stays in your browser. No uploads, no servers, no accounts.
